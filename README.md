# Omani Shoes — Order & Social Links

Premium black & gold landing page for shop QR codes.

## Deploy on Vercel

1. Import this repo in [Vercel](https://vercel.com/new)
2. Framework preset: **Other**
3. Root directory: leave default
4. Deploy — Vercel will serve `index.html`

## Local

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Links

Edit social links near the top of the `<script>` block in `index.html` (`LINKS` object).
